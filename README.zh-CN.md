# Logseq Style Fold（Logseq 风格折叠）

> **列表怎么折叠的，关掉笔记再打开还是那样 —— 用 Logseq 的写法记。**

一个 Obsidian 插件：把列表每一次折叠的状态记住。做法不是存到插件自己的文件里，而是在笔记里写一行 Logseq 的块属性。

[English](./README.md) · **简体中文**

## 为什么要它

Logseq 把折叠记成块下面的一行 `collapsed:: true`。Obsidian 不认这一行：从 Logseq 搬过来的库里它就是一行字；Obsidian 自己的折叠，笔记一关就忘。

这个插件负责读写这行标记。**默认就是 Logseq 写法**，笔记和 Logseq 互通。想用别的也行，自己配一个标记：HTML 注释 `<!-- collapsed:: true -->`、Obsidian 注释 `%% collapsed:: true %%`，或者任意一行你喜欢的文字。

## 它做什么

折叠了一项，关掉笔记，明天再打开 —— 还是折叠着的。

```markdown
- 周会纪要
	collapsed:: true
	- 数据源整理
	- 口径核对
- 待办
	- 还没折叠的项
```

标记缩进一级，紧挨着它所属的那一项 —— 跟 Logseq 放的位置一样。不管选哪种写法，插件在**所有视图里都把它藏起来**：

- **实时预览和源码模式**：这一行连同换行从视图里删掉，不是变淡也不是压扁，是没了；光标把那个位置当成一步跳过，打字撞不进去。
- **阅读视图**：渲染结果里的标记被删掉（Dataview 把 `collapsed:: true` 渲染成的内联字段也藏）。`%% … %%` 注释 Obsidian 本来就不渲染。

笔记的其他地方一个字都不动。

## 标记写法

| 写法 | 写进文件的样子 | 说明 |
|---|---|---|
| Logseq（默认） | `collapsed:: true` | 和 Logseq 一样，两边来回用都认 |
| HTML 注释 | `<!-- collapsed:: true -->` | **任何** Markdown 渲染器里都看不见：GitHub、静态博客、别的编辑器 |
| Obsidian 注释 | `%% collapsed:: true %%` | 没装插件的 Obsidian 里也看不见，但别的渲染器会把它当文字显示 |
| 自定义 | 任意一行字，比如 `[folded]` | 原样写在每个折叠项下面 |

不管你选哪种写法，`collapsed::` 这种行裸写、包在 `%% … %%` 里、包在 `<!-- … -->` 里都认，所以换写法不会丢掉已有的折叠。`collapsed:: false`（Logseq 有时会留下）当作展开；下次折叠这一项时直接改成 true，不另插一行。

### 笔记还要发到别处的话，推荐 HTML 注释

如果你的笔记还会在 Obsidian 以外被看到 —— 博客、GitHub 仓库、静态网站、别的编辑器 —— 选 **HTML 注释**写法：

- **到哪儿都干净**：所有 Markdown 渲染器都会丢掉 HTML 注释，发出去的页面上看不到任何折叠痕迹。裸写的 `collapsed:: true` 和 Obsidian 的 `%% … %%` 在那些地方都会显示成文字。
- **事后一键删干净**：标记是固定、不会和正文混淆的格式，全库用一条正则查找替换（打开多行模式）就能全部删掉，别的内容一概不碰：

  ```regex
  ^[ \t]*<!--[ \t]*collapsed::[ \t]*(?:true|false)[ \t]*-->[ \t]*\r?\n
  ```

  替换成空。只匹配整行的标记，句子里出现的同样文字不会被删。只清一篇的话，用命令「清除本文所有折叠标记」也一样。

## 怎么折叠的

折叠本身不是插件画的 —— 调的是 ⌥S 用的那个 CodeMirror 折叠。行首的箭头、行尾的 `…`、点一下展开，都是 Obsidian 自己的。有序列表折起来后，数字变深、加粗（Obsidian 默认会把它染成强调色）。

标记和折叠双向同步：

- 文件里有标记，打开笔记时就折上；别的插件或同步改写了文件、折叠丢了，也会补折。这个方向只折，不替你展开。
- 你自己折（⌥S、点箭头，平时怎么折就怎么折），标记自动写好；展开就删掉。打字、文件被改写不算折叠。
- 从别处跳到折叠里的某一行（反链、搜索结果、块引用）：包着它的折叠展开，标记一起删掉，光标停在那一行。不在折叠里的什么都不动。
- 别的插件自己折叠时，用 `app.plugins.plugins["logseq-style-fold"].quietly(() => …)` 包住，就不会被当成你的操作记下来。

## 为什么把状态写进文件

存在插件文件夹的 JSON 里、用行号或文字哈希对应，碰到经常被改写的笔记就会错位：上面插一行，行号就全变了；措辞一改，哈希就对不上。写进笔记里的一行，跟着它所属的内容走，git、同步、导出、任何保留这一块的改写都不会丢。

## 命令

| 命令 | 作用 |
|---|---|
| 折叠 / 展开光标所在的列表项 | 切换光标所在那一项（没有子项的不能折） |
| 折叠本文所有列表项 | 一次全折上 |
| 展开本文所有列表项 | 全展开 |
| 只折叠顶层的列表项 | 只折最外层，里层保持现状 |
| 清除本文所有折叠标记 | 删掉所有标记，还原成没装插件时的原文 |
| 临时露出折叠标记 | 把标记行当普通文字显示出来，检查文件里到底写了什么 |

都可以在「设置 → 快捷键」里绑快捷键。

## 设置

| 设置 | 默认 | 作用 |
|---|---|---|
| 标记写法 | Logseq | Logseq `collapsed:: true`、HTML 注释 `<!-- collapsed:: true -->`、Obsidian 注释 `%% collapsed:: true %%`，或自定义一行 |
| 鼠标划过时显示折叠按钮 | 开 | 展开着的项，鼠标划过时行尾冒出折叠按钮 |
| 折叠按钮上显示后代条数 | 开 | 显示 `⌄ 3` 而不是 `⌄` |
| 阅读视图也折叠 | 开 | 阅读视图里照标记收起列表，点小标记展开 |
| 源码模式下也折叠 | 关 | 源码模式反正会藏标记；打开后那里也折叠 |
| 临时露出折叠标记 | 关 | 把标记行当普通文字显示，排错用 |

## 安装

把 `main.js`、`manifest.json`、`styles.css` 放进 `<库>/.obsidian/plugins/logseq-style-fold/`，重启 Obsidian，在「设置 → 第三方插件」里启用 **Logseq Style Fold**。也可以用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 装 `MatsuriMW/logseq-style-fold`。

## 说明和限制

- 在 Obsidian 以外，`collapsed:: true` 会显示成文字 —— 这正是 Logseq 要的。想在别的地方也看不见，就选 HTML 注释写法。
- 标记跟着它所属的那一块走。改写把那一块删了或改了措辞，折叠状态就没了，这没办法。
- 代码块、callout、有序列表、任务列表都支持。表格里的列表不折叠。
- 标记按这一项自己文字的指纹、在同一层级里对应，所以同一篇里同一层两项文字一模一样的话，会共用折叠状态。
- 插件只写它自己的标记行，笔记里别的东西一概不动。
